# Video Bulk Remixer

Tool chạy trên máy của bạn để tạo hàng loạt biến thể video quảng cáo: thay đoạn đầu/giữa/cuối, thay audio, thay chữ theo ngôn ngữ, đặt tên tự động và có báo cáo kết quả. Không gửi video lên mạng.

## Cách cài và dùng

Xem hướng dẫn chi tiết, có hình minh hoạ, cho cả Mac và Windows:
- Bản PDF: [HUONG-DAN-CAI-DAT.pdf](HUONG-DAN-CAI-DAT.pdf)
- Bản Markdown: [docs/HUONG-DAN-CAI-DAT.md](docs/HUONG-DAN-CAI-DAT.md)

Tóm tắt:
1. Cài Python 3.12.
2. Đặt `ffmpeg` và `ffprobe` vào thư mục `bin/`.
3. Mac: nhấp đúp `RUN-Mac.command`. Windows: nhấp đúp `RUN-Windows.bat`.
4. Mở link hiện trong cửa sổ đen/Terminal bằng trình duyệt.

## Yêu cầu
- Python 3.12 (không dùng bản 3.9 mặc định của Mac, không dùng bản 3.14 trở lên).
- ffmpeg và ffprobe.
